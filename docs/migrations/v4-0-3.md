# v4.0.3 Config Migration

This note covers the project-config compatibility break between v4.0.2 and v4.0.3.

## Breaking change

Top-level `allowWrites` and `allowedProcedures` loaded successfully in v4.0.2. Starting with v4.0.3, either field produces `CONFIG_TOP_LEVEL_FIELDS_REMOVED`.

## Migration

1. Preview the proposed rewrite with `migrate_project_config({ apply: false })`.
2. Review the returned diff and remediation entries.
3. Rewrite the file with `migrate_project_config({ apply: true })`.
4. Retry the original Dysflow operation.

The migration moves the fields to `capabilities.allowWrites` and `capabilities.procedures.allow`.
